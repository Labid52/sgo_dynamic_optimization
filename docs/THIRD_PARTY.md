These `.m` files are redistributed here **only** so that the equivalence gate
(`code/gmpb_equivalence.py`) and the state generator (`code/gmpb_generate.sh`) can be
run without a separate download. **The upstream repository does not carry an explicit
open-source licence file.** If you intend to redistribute this package further, or if
your institution requires an explicit licence for every redistributed file, obtain the
four `.m` files directly from the upstream repository instead: delete
`data/gmpb/octave/official/`, clone EDOLAB-MATLAB, and copy the four files back into
the same paths. Verify them against the hashes above before use. Nothing else in this
package depends on those files being present — the committed raw data and the whole
Level-1 analysis path work without them.

Files under `data/gmpb/octave/` that are **not** in `official/` (`gmpb_dump.m`,
`gmpb_refrun.m`, `shim/pdist2.m`) are authored in this project. They only drive and
serialize the official generator; they do not reimplement it.

## Reference solvers

Called as libraries, not redistributed: OSQP (Apache-2.0), and SciPy's L-BFGS-B
(BSD-3-Clause). See `requirements.txt` for pinned versions.

## Algorithms reimplemented in this project

SGO, GWO, PSO and WOA under `code/` are independent Python implementations written for
this study from the published descriptions; no third-party source was copied. Their
sources are:

- SGO — M. Azizi, M. Baghalzadeh Shishehgarkhaneh, M. Basiri, R. C. Moehler,
  "Squid Game Optimizer (SGO): a novel metaheuristic algorithm,"
  *Scientific Reports* 13:5373 (2023). doi:10.1038/s41598-023-32465-z.
  This is the Squid Game Optimizer, **not** Social Group Optimization, which shares
  the acronym.
- GWO — S. Mirjalili, S. M. Mirjalili, A. Lewis, *Advances in Engineering Software* 69 (2014).
- PSO — J. Kennedy, R. Eberhart (1995), with the inertia weight of Shi & Eberhart (1998).
- WOA — S. Mirjalili, A. Lewis, *Advances in Engineering Software* 95 (2016).

## MPC plant models

The five MPC systems in `code/system_defs.py` are transcribed from published sources
and are cited in the manuscript: the pendulum-cart case study of Brunton & Kutz, the
CSTR deviation model from the MATLAB MPC documentation, the aircraft longitudinal model
of Klee & Allen, the 13-state building thermal model of Maasoumy, and a 12-state
small-angle quadcopter model.
